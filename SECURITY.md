# Sicherheit

## Schwachstellen melden

Bitte melde Sicherheitslücken nicht öffentlich, sondern über die Funktion „Report a vulnerability“
(GitHub Security Advisories) im Repository `WayneNani/better-maps`. Betrifft die Lücke Code, der unverändert aus
CoMaps stammt, melde sie bitte zusätzlich dem Upstream-Projekt (https://codeberg.org/comaps/comaps).

## Signaturen

Better Maps veröffentlicht noch keine signierten Builds. Sobald es Releases gibt, stehen hier die Fingerabdrücke der
Signaturzertifikate. APKs, die mit dem Schlüssel von CoMaps signiert sind, stammen nicht von Better Maps.
